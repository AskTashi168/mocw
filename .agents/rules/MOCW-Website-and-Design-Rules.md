# MOCW Website and Design Rules

## 1. Purpose

The MOCW website must feel like a professional, trustworthy and welcoming place that people would want to:

* Visit again.
* Spend time exploring.
* Share with someone who may appreciate or need MOCW.
* Return to when they need a thoughtful conversation or another perspective.

The website must communicate the character of **My One Cent Worth (MOCW)**:

> Someone Who Listens.

The design should support the message, not compete with it.

---

## 2. Overall Design Direction

The website must have one consistent visual identity across every page.

The design should feel:

* Dark.
* Warm.
* Refined.
* Modern.
* Calm.
* Thoughtful.
* Human.
* Trustworthy.
* Professional.
* Easy to use.
* Comfortable to read.

Avoid designs that feel:

* Noisy.
* Crowded.
* Childish.
* Overly corporate.
* Excessively luxurious.
* Aggressive.
* Cold.
* Generic.
* Full of unnecessary animations or effects.

The website should feel carefully designed without looking over-designed.

**Professional does not mean complicated.**

---

## 3. Consistent Website Identity

All pages must look like part of the same website.

The following elements must remain consistent across the website:

* Colour palette.
* Typography.
* Logo treatment.
* Navigation.
* Button styles.
* Page width.
* Content spacing.
* Image treatment.
* Section headings.
* Cards.
* Forms.
* Footer.
* Responsive behaviour.
* Back-to-top button.
* WhatsApp contact button, where appropriate.

Each page may have a different layout according to its purpose, but it must still feel unmistakably like MOCW.

> Consistent identity. Different experiences.

---

## 4. Shared Stylesheet

Use the shared `mocw.css` stylesheet for common design elements, including:

* Colours.
* Typography.
* Page width.
* Spacing.
* Navigation.
* Hero and banner styles.
* Buttons.
* Cards.
* Forms.
* Footer.
* Responsive layouts.
* Image sizing.
* Back-to-top button.
* Floating contact button.
* Repeated page elements.

Do not create unrelated styles for individual pages.

Page-specific CSS may be used only when a page genuinely requires a different layout or feature.

Any page-specific styling must still follow the MOCW visual identity.

---

## 5. Page Width and Content Alignment

The website must use a comfortable and professional content width.

Content should not stretch unnecessarily across very wide desktop screens.

Use a consistent maximum content width for:

* Main content.
* Section headings.
* Text and image layouts.
* Cards.
* Footer content.

Text should remain easy to read.

Avoid:

* Extremely long lines of text.
* Content pressed against the browser edges.
* Uneven left and right margins.
* Sections that appear wider or narrower without a clear reason.
* Random changes in content width between sections.

The page should feel balanced on large screens.

---

## 6. Desktop, Tablet and Mobile Design

The website must be designed and checked for all three screen sizes:

1. Mobile phones.
2. Tablets.
3. Desktop and large desktop screens.

**Mobile-first must not mean mobile-only.**

The agent must not design mainly for mobile and then simply stretch the layout for desktop.

Each screen size must receive proper attention.

### Mobile

Mobile pages must have:

* Readable text.
* Comfortable spacing.
* Large enough buttons.
* Simple navigation.
* Properly sized images.
* No unnecessary horizontal scrolling.
* Clear content hierarchy.
* Sections that do not feel cramped.
* Text that does not become too small.

### Tablet

Tablet pages must have:

* Properly balanced two-column layouts where suitable.
* Comfortable image and text widths.
* Correct spacing between sections.
* Navigation that remains clear and usable.
* No awkward empty spaces.
* No desktop layout squeezed into a narrow screen.
* No mobile layout unnecessarily stretched across the screen.

### Desktop

Desktop pages must have:

* Professional visual balance.
* Proper use of available screen width.
* Well-proportioned image and text columns.
* Consistent section spacing.
* Clear visual hierarchy.
* Comfortable reading widths.
* Strong alignment between headings, images and text.
* No oversized empty spaces.
* No narrow mobile-style content floating in the middle of a large screen unless intentionally designed that way.

The agent must check the actual appearance at mobile, tablet and desktop widths before considering a page complete.

---

## 7. Navigation and Hero/Banner

Every page must have a suitable hero or banner treatment.

The MOCW main navigation should overlay the main hero or banner image where appropriate.

The navigation must feel integrated into the hero rather than appearing as a separate unrelated block.

The agent must ensure:

* The MOCW logo is clearly visible.
* Navigation links are readable.
* The navigation does not disappear into the image.
* The hero image does not overpower the navigation.
* Important text is not hidden behind the navigation.
* The navigation remains usable on tablet and desktop.
* The mobile navigation is simple and easy to use.
* The hero is not excessively tall on mobile.
* The hero image is correctly cropped at different screen sizes.
* The main heading remains visible and well positioned.
* Buttons remain visible and easy to use.

Pages without a traditional image must still have a suitable banner treatment using spacing, colour, typography or a carefully selected visual element.

The main navigation must remain consistent throughout the website.

---

## 8. Page Structure

Each main page should include, where appropriate:

* Consistent navigation.
* A suitable hero or banner.
* One clear main heading.
* A short introduction.
* Well-organised sections.
* Clear section headings.
* Readable content.
* Suitable images, videos or visual elements.
* Useful internal links.
* A clear next step.
* Consistent footer.
* Back-to-top button on longer pages.

Every page should have a clear purpose.

Do not add sections simply to make a page longer.

---

## 9. Section Layout and Spacing

Section spacing must be consistent and intentional.

The website must not look as though each section was created separately and then placed one after another.

Every section should have:

* A clear beginning.
* A clear heading.
* Comfortable space above and below.
* Consistent alignment.
* A logical relationship between text and images.
* Enough breathing room without creating excessive empty space.

Avoid:

* Sections touching each other.
* Large unexplained gaps.
* Random changes in spacing.
* Headings too close to the previous section.
* Images too close to the next section.
* Text beginning much higher or lower than the image beside it.
* Uneven spacing between similar sections.

The spacing between similar sections should be similar throughout the page.

---

## 10. Text and Image Alignment

When a section uses two columns, such as:

* Video on the left and text on the right.
* Image on the left and text on the right.
* Text on the left and image on the right.

The text and visual element must begin at a visually balanced height.

Do not allow the image to begin at one height while the text begins much higher or lower without a clear design reason.

If the text is too long to align naturally with the image:

* Summarise the text.
* Use shorter paragraphs.
* Use a clear introductory paragraph.
* Move additional information into another section.
* Use a suitable internal link.

Do not solve poor alignment by allowing a large block of text to extend far below the image.

The section should feel balanced, calm and easy to scan.

---

## 11. Section Headings

Section headings should look professional and consistent.

Unless there is a strong design reason otherwise:

* Centre the main section headings.
* Use consistent heading sizes.
* Use consistent colour and typography.
* Keep headings short and meaningful.
* Allow headings to wrap naturally on smaller screens.
* Avoid headings being too close to the content above or below.

Main page headings and section headings must have a clear visual hierarchy.

Do not use oversized headings that overpower the content.

Do not use inconsistent heading alignment from one section to another without a clear reason.

---

## 12. Text Presentation

Text must be easy to read and professionally arranged.

Use:

* Short paragraphs.
* Comfortable line spacing.
* Clear paragraph spacing.
* Strong opening sentences.
* Meaningful subheadings.
* Occasional bold text for important ideas.
* Italics only where useful.
* Lists when they improve readability.

Avoid:

* Large walls of text.
* Unnecessary repetition.
* Excessively wide text blocks.
* Random bolding.
* Too many different font sizes.
* Text that is too small.
* Text that is tightly packed.
* Text that appears unfinished or poorly edited.

The website should communicate clearly without overwhelming visitors.

---

## 13. Content Summaries

When a section contains a long explanation beside an image, video or graphic, the agent should consider summarising the text.

The purpose is to create:

* Better visual balance.
* Easier reading.
* Stronger presentation.
* More professional spacing.
* A clearer message.

Important details may be moved to:

* Another section.
* A dedicated page.
* An internal link.
* A “Read More” area, where appropriate.

Do not place an entire long article beside a small image if it damages the layout.

---

## 14. Images and Videos

Images and videos must support the message of the page.

The agent must ensure:

* Images are sharp and correctly sized.
* Images are not stretched or distorted.
* Important subjects are not cropped incorrectly.
* Images have consistent corner treatment where appropriate.
* Image proportions are consistent within similar sections.
* Videos are displayed at a suitable size.
* Video thumbnails do not dominate the page.
* Images do not create unnecessary page height.
* Images work properly on mobile, tablet and desktop.

Images should feel intentional rather than randomly inserted.

The MOCW logo, mugs, one-cent imagery and other brand elements should be used consistently.

---

## 15. Cards and Repeated Content

Cards should be used only when they improve understanding or organisation.

Cards must have:

* Consistent spacing.
* Consistent borders or backgrounds.
* Consistent corner treatment.
* Clear headings.
* Readable text.
* Balanced internal padding.

Avoid:

* Too many cards.
* Cards with excessive text.
* Uneven card heights where avoidable.
* Random card designs on different pages.
* Cards that look like unrelated website components.

Repeated cards should follow the same visual rules.

---

## 16. Buttons and Calls to Action

Buttons must be clear, readable and consistent.

Buttons should:

* Use straightforward wording.
* Have comfortable padding.
* Be large enough to tap on mobile.
* Stand out without being aggressive.
* Use the MOCW colour palette.
* Have consistent hover and focus behaviour.
* Clearly communicate what happens when clicked.

Use clear calls to action such as:

* Talk to Me on WhatsApp.
* Learn More.
* Explore MOCW.
* View Services.
* Contact Me.

Do not add buttons that do not perform a useful action.

---

## 17. WhatsApp Contact Button

The WhatsApp contact button should remain available where appropriate.

It must:

* Be easy to recognise.
* Be positioned consistently.
* Remain visible without covering important content.
* Work on mobile, tablet and desktop.
* Not cover text, buttons, images or forms.
* Use an accessible size.
* Open the correct WhatsApp destination.

The floating button must not become visually distracting.

---

## 18. Back-to-Top Button

Long pages should include a clear and working Back-to-Top button.

This is especially important for:

* About pages.
* Mission and Vision pages.
* FAQ pages.
* Service pages.
* Long articles.
* Knowledge pages.
* Long quizzes.
* Interactive tools.

The button must:

* Work on mobile, tablet and desktop.
* Be easy to find.
* Not cover important content.
* Use consistent MOCW styling.
* Return the visitor smoothly to the top of the page.

---

## 19. Footer

The MOCW footer must appear consistently across all pages.

The footer should include, where appropriate:

* MOCW branding.
* My One Cent Worth name.
* MOCW short-form name.
* “Someone Who Listens.”
* A brief description of MOCW.
* Useful navigation links.
* Contact link.
* Legal links.
* Copyright information.
* Relevant sitemap links, where required.

The footer must:

* Use the same overall design across the website.
* Have balanced spacing.
* Be readable on mobile, tablet and desktop.
* Not feel crowded.
* Not appear unfinished.
* Remain visually connected to the rest of the website.

The footer is a shared website element and must not be redesigned separately for individual pages without a strong reason.

---

## 20. Search and AI-Friendly Content

Important pages should include:

* A clear page title.
* A useful meta description.
* One clear main heading.
* Descriptive section headings.
* Natural language.
* Helpful internal links.
* Answers to real visitor questions.
* Clear explanations of what MOCW is and is not.

Content should help both people and search engines understand:

* Who Tashi is.
* What My One Cent Worth means.
* What MOCW means.
* What “Someone Who Listens” means.
* Why MOCW was created.
* What MOCW offers.
* Who may benefit from MOCW.
* What MOCW is not.
* How visitors can take the next step.

Do not use keyword stuffing.

Do not repeat the same wording unnecessarily.

Write for real people first.

---

## 21. Website Simplicity

Use:

* HTML.
* CSS.
* Vanilla JavaScript.
* The existing PWA structure where applicable.
* Existing folders and assets.
* The shared `mocw.css` stylesheet.

Do not introduce unnecessary:

* Frameworks.
* Plugins.
* Page builders.
* Dependencies.
* Folder systems.
* Hosting systems.
* Technical complexity.

The website should remain easy to maintain and understandable to a non-technical owner.

Do not replace working structures unless there is a clear and necessary reason.

---

## 22. Quality Check Before Completion

Before declaring a page complete, the agent must check:

### Design

* Does the page look professional?
* Does it feel unmistakably like MOCW?
* Is the design calm, warm and trustworthy?
* Does the design support the message?

### Layout

* Are the sections properly spaced?
* Are the headings aligned consistently?
* Do text and images begin at balanced heights?
* Are there unnecessary gaps?
* Are any sections too crowded?
* Does the page look balanced on large screens?

### Responsive Views

* Does the page work on mobile?
* Does the page work properly on tablet?
* Does the page work properly on desktop?
* Has the desktop layout received proper attention?
* Has the tablet layout received proper attention?
* Is there any horizontal scrolling?
* Are images and text correctly sized at every screen width?

### Navigation and Footer

* Is the navigation consistent?
* Does the navigation overlay the hero or banner appropriately?
* Is the logo visible?
* Is the footer present?
* Does the footer match the rest of the website?

### Usability

* Are buttons clear?
* Do links work?
* Does the WhatsApp button work?
* Does the Back-to-Top button work on long pages?
* Are important actions easy to find?

### Content

* Is the text clear?
* Are long sections summarised where necessary?
* Is there unnecessary repetition?
* Does the page have a clear purpose?
* Is there a useful next step?

---

## 23. Final Design Principle

The MOCW website should not merely look acceptable.

It should feel like a website created with care, thought and respect for the visitor.

Visitors should be able to understand MOCW easily, move through the website comfortably, and remember the experience after they leave.

> Create a professional website that people would want to return to, recommend and share with someone who may appreciate or need MOCW.
